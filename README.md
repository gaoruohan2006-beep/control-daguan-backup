# 控制考研真题大观园

**[打开刷题网站](https://gaoruohan2006-beep.github.io/control-daguan-backup/)**

默认按专题和考点刷题，亦可在题单菜单中切换到「按院校」。题卡支持收藏、笔记和间隔复习。现代控制理论中的状态空间方法和最优控制分别设有专题。

已从汇编中 24 所 985 高校的 79 份试卷选录题目。211 专篇所列的 29 所院校、91 份 2023–2025 年试卷均已有题目入库。双非院校篇所列的 18 所院校有 52 份 2023–2025 年试卷各选录一题。可通过「按院校」或搜索「双非」「211」查看相应题目。题面和解析使用 LaTeX。框图、工程示意图及函数曲线以 SVG 显示，可点击放大。同一道题只显示一张卡片。

《起点精选1000题》的题目同样可按院校或专题查找。搜索「起点精选1000题」可筛出书册题，包括已并入院校题的重复题。现有 731 道独立题卡：434 道院校题与 297 道精选练习。第二批结合题本、答案册及 8 月勘误核对了 238 处书册题目，合并 38 处重复，实际新增 200 道。

书册进度：A 册第一至三章已整理完，第四章至选择题11、填空题8；下一题从第四章填空题9继续。详细复核记录见 `qa/2026-11-18-next200/README.md`。

## 本地运行

```powershell
python -m http.server 8765 --bind 127.0.0.1 -d public
```

打开 [本地题库](http://127.0.0.1:8765/)。

审核通过的题卡存于 `data-src/reviewed/`，配图存于 `public/img/reviewed/`。修改后运行 `python tools/build_reviewed_bank.py` 更新网站数据。原版仓库历史保存在 Git 的提交记录中。
