## 2. questions.json 结构

```json
{
  "year": 2017,
  "contributor": "workbuddy",
  "questionPages": "26–28",
  "answerPages": "115–122",
  "questions": [
    {
      "no": 3,
      "score": null,
      "cats": ["根轨迹 / 常规根轨迹绘制", "时域分析 / 稳态误差 / 静态误差系数"],
      "stem": "$$G(s)=\\frac{K(s+4)}{s(s+2)(s+15)}$$\n\n1、绘制其根轨迹；\n\n2、……",
      "figures": ["img/q2017-3-1.png"],
      "answerImages": ["img/a2017-3-1.png", "img/a2017-3-2.png"],
      "answer": "",
      "explanation": "",
      "notes": "源答案第 2 问结论有误：……（可选，写给维护者看）"
    }
  ]
}
```

字段说明：

| 字段 | 必填 | 说明 |
| ---- | ---- | ---- |
| `no` | 是 | 大题序号 1、2、3…（一、二、三… 对应 1、2、3…） |
| `score` | 否 | 试卷标注的分值（整数）；没标就写 `null` |
| `cats` | 是 | 1–3 条分类路径，第一条为主分类。格式 `专题 / 子类[ / 细类]`，**专题必须取自第 3 节** |
| `stem` | 是 | 题干，Markdown + LaTeX，见第 4 节。配图用占位符 `[[fig:1]]`、`[[fig:2]]`… 放在原文出现的位置 |
| `figures` | 是 | 与占位符一一对应的图片相对路径；没有图就写 `[]`。占位符个数必须等于 `figures` 长度 |
| `answerImages` | 是 | 本题答案页截图，按顺序；至少 1 张 |
| `answer` / `explanation` | 否 | 可留空字符串。留空时网站的「答案」「解析」按钮直接显示原图 |
| `notes` | 否 | 发现源答案错印、缺步骤、题图错位等，写在这里 |

## 4. 题干写法

- 段落之间空一行（JSON 里是 `\n\n`）。每个小问单独一段，保留原题编号写法（`1、` / `1.` / `（1）`）。
- 行内公式 `$...$`，独立公式 `$$...$$`。JSON 里反斜杠要写两次：`\\frac`。
- 矩阵用 `\begin{bmatrix}…\end{bmatrix}`；分式 `\dfrac`；百分号写 `\sigma\%`；单位写 `\,\mathrm{rad/s}`。
- **不要**照抄 pdftotext 的输出：Word 转 PDF 的分式、上下标、希腊字母（ω、ζ、σ、∞ 常丢失）会乱。务必对照页面图核对每个公式。
- 能用 LaTeX 写清楚的矩阵和传递函数写成 LaTeX；结构图、电路、曲线图用裁剪的配图。
- 题干里不要出现页眉页脚、广告、机构名。

## 5. 去广告、去水印、裁图

每页都有广告页眉（“控制考研哪家强，万人教育来领航”、QQ 群号）和页脚（公众号、微信、“小白学长 QQ”、页码），背景有紫色“万人教育”水印。

- **水印**：用 `clean.pdf` 出图即可（水印图片对象 5 0 R 的软蒙版已经清零，渲染出来就是白底）。
- **页眉页脚**：只裁 y ∈ [57, 764] pt 之间的内容。
- **答案里的“【万人教育解析】/【万人教育解题】”字样**：要涂白，工具会自动处理。

推荐直接用共享工具 `incoming/tools/cdg_crop.py`（坐标单位 pt，页面 595×842，原点左上）：

```bash
T=/workspace/control-daguan/incoming/tools/cdg_crop.py
python3 $T grid 27                      # 生成 /workspace/cdg/pages/grid-027.png，带 50pt 网格，用来量图的坐标
python3 $T fig 27 110 300 480 420 /workspace/control-daguan/incoming/2017/img/q2017-2-1.png   # 裁题图（自动去白边）
python3 $T ans 2017 /workspace/control-daguan/incoming/2017/img_ans_raw   # 自动按标记切答案 → ans-<题号>-<k>.png
```

`ans` 会打印 `{"1": ["ans-1-1.png", …], …}`。把文件重命名成 `a<年份>-<题号>-<k>.png` 放进 `img/`，并逐张目检：

- 开头是本题的“一、二、…”；
- 不含下一题的内容；
- 没有页眉页脚残留；
- 题号数与试卷一致（若某题标记缺失或格式特殊导致合并、错位，手动用 `fig` 截取）。

配图要求：PNG，200 dpi（工具默认），包含图名，比如“(a)”“图 1”。框外的文字不要截进来。

## 6. 自检清单

1. `python3 -c "import json;json.load(open('questions.json'))"` 能通过。
2. 每题 `[[fig:N]]` 个数 = `len(figures)`，所有路径的文件都存在。
3. 题目数量与试卷一致，`no` 连续。
4. KaTeX 能渲染：维护者会用 `katex` 跑一遍，报错的题会退回。
5. 完成后 `touch incoming/<年份>/DONE`。
